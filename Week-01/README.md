# Week 1 – SIEM Architecture & Log Onboarding

## Overview
This week focuses on deploying a Wazuh SIEM lab, onboarding endpoints, verifying log collection, and developing a log retention plan.

## Tools & Technologies
- Wazuh 4.14.9
- Ubuntu Server 26.04 LTS
- Kali Linux
- VirtualBox
- OpenSearch

## Work Completed
- Deployed Wazuh Manager, Indexer, and Dashboard.
- Onboarded a Kali Linux endpoint using the Wazuh agent.
- Verified event collection and alert visibility in Threat Hunting.
- Documented SIEM architecture and data source inventory.
- Analyzed log field mapping and normalization.
- Implemented a 90-day alert retention policy.
